# EarnGrind Codex Workflow

This directory is for reusable Codex workflow assets that support evidence-backed EarnGrind SEO research guides.

The current approach is skill-first: keep the research procedure, evidence rules, templates, and evaluation notes simple and local before packaging anything as a full Codex plugin. Plugin packaging can come later after the workflow has been used on real guide tasks and the repeated steps are clear.

Do not put production app code, database migrations, or generated research evidence in `.codex/`.
