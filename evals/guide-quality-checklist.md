# EarnGrind Guide Quality Checklist

Use this checklist after a guide workflow run produces research artifacts, angle work, SEO metadata, FAQ candidates, or a final draft.

Score each category from 1 to 5 using `scoring-rubric.md`. Add notes with file paths, source URLs, screenshot paths, or missing evidence.

## Checklist

| Category | Score | Notes |
| --- | ---: | --- |
| Evidence quality |  | Are important claims backed by source URLs plus screenshot paths or extracted text? |
| Screenshot usefulness |  | Do screenshots prove meaningful public-page claims rather than decorative pages? |
| Accuracy |  | Are payouts, bonuses, withdrawals, timelines, provider rules, and eligibility details copied only from evidence? |
| SEO completeness |  | Are SEO title options, meta descriptions, H1, suggested slug, FAQ candidates, and source-aware headings present? |
| Practical user value |  | Does the guide explain who the site fits, who should avoid it, and what users should do next? |
| Conversion angle |  | Is the primary angle useful for EarnGrind readers and aligned with a plausible CTA without overclaiming? |
| Internal linking suggestions |  | Are suggested links relevant to EarnGrind offers, games, guides, platforms, and blog pages? Are unverified routes labeled as suggestions? |
| Unsupported claims avoided |  | Are unsupported payout amounts, guaranteed earning claims, legal/financial claims, and invented provider rules absent? |
| Site-specificity |  | Does the output feel specific to this site rather than a generic GPT/rewards review? |

## Required Pass Checks

- No important factual claim is missing evidence.
- Uncertain claims are clearly marked.
- No made-up payout, withdrawal, bonus, deadline, eligibility, or provider-rule claim appears.
- `facts.json`, `sources.md`, and screenshots are traceable from the draft or metadata.
- The guide can be published only after human review.
